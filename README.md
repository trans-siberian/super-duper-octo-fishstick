# Super Duper Octo Fishstick

A small vanilla-friendly BTA! 8.0+ Babric mod that adds several building blocks.<br>
Currently includes:

- Stairs and slabs for every regular stone variant
- Tiles blocks for stone, limestone, granite, basalt and marble, aswell as checkered tiles
- Smooth sandstone
- Polished limestone bricks
- Checkered tiles
- Shored sand & gravel, which are not affected by gravity
- Compressed versions of cobblestone, mossy cobblestone, polished stone, polished stone tiles and polished netherrack
- Iron & steel plating blocks
- Small marble & lapis tiles
- Vent block (purely decorational)
